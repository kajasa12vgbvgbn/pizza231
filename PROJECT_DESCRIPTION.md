# 🛒 Интернет-магазин — Описание проекта

## 📌 Назначение
Веб-приложение интернет-магазина с каталогом товаров, корзиной, системой регистрации пользователей и панелью администратора.

## 🛠 Стек технологий
- **Backend:** PHP (без фреймворка, собственная MVC-архитектура)
- **База данных:** MySQL (с fallback на JSON)
- **Архитектура:** MVC (Model-View-Controller)
- **API:** REST API (JSON)

## 🚀 Установка и запуск

### Требования
- PHP >= 7.4
- MySQL >= 5.7
- Веб-сервер (Apache/Nginx) или встроенный PHP-сервер

### Шаги установки
```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd <project-folder>

# 2. Настройте конфигурацию
# Отредактируйте config/Config.php для подключения к БД

# 3. Запустите встроенный сервер (для разработки)
php -S localhost:8000

# Или используйте встроенный скрипт
php migrate.php  # Миграция БД
php optimize_db.php  # Оптимизация БД
```

## 🔌 API Endpoints

### Товары
- `GET /api/product/{id}` — Получить товар по ID

### Корзина
- `POST /api/cart/add` — Добавить товар
- `POST /api/cart/update` — Обновить количество
- `POST /api/cart/remove` — Удалить товар
- `POST /api/cart/clear` — Очистить корзину
- `POST /api/cart/order` — Оформить заказ

### Авторизация
- `POST /api/auth/register` — Регистрация
- `POST /api/auth/login` — Вход
- `POST /api/auth/logout` — Выход
- `POST /api/auth/verify` — Верификация email
- `POST /api/auth/resend` — Повторная отправка письма

### Админка
- `GET /api/admin/stats` — Статистика
- `GET /api/admin/orders` — Список заказов
- `GET /api/admin/users` — Список пользователей
- `GET /api/admin/logs` — Логи
- `GET /api/admin/products` — Список товаров
- `POST /api/admin/product` — Создать товар
- `PUT /api/admin/product/{id}` — Обновить товар
- `DELETE /api/admin/product/{id}` — Удалить товар
